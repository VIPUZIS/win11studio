# Win11Studio Dynamic Engine v5.0

**Win11Studio** — это автоматизированный графический инструмент на базе PowerShell и DISM, предназначенный для глубокой инспекции, очистки, оптимизации и пересборки официальных дистрибутивов Windows 11. Утилита позволяет создать облегченный и конфиденциальный установочный образ системы под свои нужды через удобный графический интерфейс.

## 🚀 Основные возможности

### 1. Управление редакциями и обход ограничений (Bypass)
* **Режимы сборки:** Поддержка создания All-In-One (AIO) образов (патчи применяются ко всем редакциям внутри `install.wim`) или обработка только конкретного индекса.
* **Bypass установщика:** Автоматическое вшивание обхода системных требований Windows 11 в `boot.wim` (отключение проверок на TPM 2.0, SecureBoot, объем ОЗУ, поддерживаемый процессор и минимальный размер диска).

### 2. Динамический сканер компонентов (AppX)
* **Умный анализ:** Временное монтирование ISO в режиме "только чтение" для сканирования фактически присутствующих в дистрибутиве встроенных приложений.
* **Удаление «мусора»:** Возможность вручную или автоматически (по шаблонам) выбрать и полностью вырезать предустановленный софт, такой как Cortana, Copilot, Bing, Xbox, OneDrive, реклама и встроенные игры.

### 3. Оптимизация FOD (Компоненты по требованию) и Ролей
* **Удаление лишних компонентов (Capabilities):** Вырезание распознавания лиц Windows Hello, рукописного ввода, OCR, математической панели, WordPad, устаревшего PowerShell v2.0 и др.
* **Отключение системных функций:** Полное отключение небезопасного протокола SMB 1.0, TFTP, Telnet и ИИ-компонента Windows Recall на уровне реестра и DISM.

### 4. Кастомизация первого запуска (OOBE Wizard)
* **Win11Studio OOBE Wizard:** Интеграция собственного графического скрипта, который запускается перед рабочим столом и позволяет пользователю применить финальные твики (отключить поисковые подсказки Bing, активировать максимальную производительность Ultimate Performance, настроить UAC).
* **Локальный профиль:** Автоматический обход требования обязательного сетевого входа и учетной записи Microsoft (инъекция `autounattend.xml` с флагом BypassNRO).

### 5. Интеграция драйверов
* Добавление сторонних драйверов запоминающих устройств и контроллеров (NVMe, RAID, Intel VMD) как в сам установщик (`boot.wim`), чтобы процесс установки видел жесткие диски, так и в развертываемую систему.

### 6. Сжатие и очистка (WinSxS)
* **Сброс базы компонентов (`/ResetBase`):** Удаление всех старых версий обновлений, что уменьшает размер WIM-файла на 1–3 ГБ.
* **Ультра-сжатие:** Перепаковка результирующего образа с использованием максимального сжатия LZX.

## 📂 Структура рабочего окружения

Скрипт автоматически разворачивает изолированную рабочую директорию `Win11Studio_Workspace` в корне своей папки:
* `\Mount` — папка для временного монтирования WIM/ESD образов.
* `\ISO_Extracted` — папка для распаковки файлов дистрибутива.
* `\Drivers` — каталог для размещения ваших сторонних драйверов (`.inf`).
* `\Tweaks` — каталог под кастомные модификации.

## 🛠 Требования для работы

1. **ОС:** Windows 10 / 11 (запуск с правами Администратора).
2. **Инструменты:** Для финальной сборки ISO требуется утилита `oscdimg.exe` (входит в состав Windows ADK / Deployment Tools). Если она установлена по умолчанию, скрипт определит её автоматически.
3. **Права:** Разрешение на запуск PowerShell скриптов (`Set-ExecutionPolicy Bypass`).

## 📖 Инструкция по использованию

1. Запустите скрипт от имени **Администратора**.
2. На вкладке **«Источник и Редакции»** выберите исходный ISO-образ Windows 11.
3. Перейдите во вкладку **«Сканер состава ISO»**, нажмите кнопку `Сканировать образ` и отметьте галочками приложения, которые хотите удалить.
4. Настройте необходимые компоненты, драйверы и параметры OOBE на соответствующих вкладках.
5. Нажмите кнопку `🚀 Собрать финальный ISO` на левой панели и дождитесь окончания процесса (прогресс будет отображаться в логе и на ProgressBar). Готовый образ сохранится в папке со скриптом.
6. При возникновении ошибок или для очистки кэша используйте кнопку `Сбросить кэш монтирования`.
